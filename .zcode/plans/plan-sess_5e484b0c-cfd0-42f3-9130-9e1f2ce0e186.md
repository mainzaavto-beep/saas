# План: Профиль, настройки проекта, магазины, сотрудники

## Решения
- **Cabinet в БД** (RLS не трогаем), **«Проект» в UI**
- **Несколько магазинов одного МП** — меняем PK `cabinet_marketplaces` (добавляем `shop_id`)
- **Сотрудники** — по инвайт-ссылке (token)

## ЭТАП 1 — Миграция 010: структура

**auth.users** — добавить поля профиля:
- `first_name TEXT`, `last_name TEXT`, `patronymic TEXT`
- `phone TEXT`
- `updated_at TIMESTAMPTZ`

**auth.shops** (НОВАЯ, замена cabinet_marketplaces):
```sql
CREATE TABLE auth.shops (
    shop_id     BIGSERIAL PK,
    cabinet_id  BIGINT → cabinets,
    mp_code     TEXT,        -- wb|ozon|ya|avito
    shop_name   TEXT,        -- "ИП Матвеев WB", "Мяумолл Ozon"
    legal_name  TEXT,        -- ИП/ООО (разные юрлица)
    api_creds_enc TEXT,      -- шифртованные ключи (pgcrypto)
    is_active   BOOLEAN DEFAULT true,
    created_at  TIMESTAMPTZ
);
```
Один проект → много shop, каждый shop = один кабинет МП.

**auth.invitations** (НОВАЯ):
```sql
CREATE TABLE auth.invitations (
    token       TEXT PK,        -- uuid
    cabinet_id  BIGINT → cabinets,
    role        TEXT,            -- manager|viewer
    email       TEXT,            -- кому (опционально)
    created_by  BIGINT → users,
    accepted_by BIGINT → users,  -- кто принял
    accepted_at TIMESTAMPTZ,
    expires_at  TIMESTAMPTZ
);
```

## ЭТАП 2 — API: профиль + настройки

**/api/profile** (GET/PUT):
- GET: ФИО, телефон, email
- PUT: обновить ФИО, телефон
- POST `{old_password, new_password}`: смена пароля

**/api/cabinets/[id]/settings** (GET/PUT):
- GET: display_name, tax_mode (usn_pct, vat)
- PUT: обновить название, налоги

**/api/cabinets/[id]/shops** (GET/POST/DELETE):
- GET: список магазинов (shop_id, mp_code, shop_name, legal_name, has_creds)
- POST: добавить магазин (mp_code, shop_name, legal_name, api_creds)
- DELETE: удалить магазин

**/api/cabinets/[id]/members** (GET):
- GET: список сотрудников (user_id, name, email, role)

**/api/cabinets/[id]/invites** (POST/GET/DELETE):
- POST: создать инвайт (role, email?) → отдаёт token/ссылку
- GET: список активных инвайтов
- DELETE: отозвать инвайт

**/api/invite/[token]** (GET/POST):
- GET: проверить инвайт (cabinet_name, role)
- POST: принять (создать membership)

## ЭТАП 3 — Фронты (5 экранов)

**/settings** — профиль пользователя:
- ФИО (3 поля), телефон, email (RO)
- Смена пароля (старый + новый + подтверждение)

**/cabinets/[id]/settings** — настройки проекта:
- Название проекта
- Налоги (УСН %, НДС)
- Управление магазинами (список + добавить/удалить)
- API ключи по каждому магазину

**/cabinets/[id]/team** — команда:
- Список сотрудников (ФИО, email, роль)
- Создать инвайт-ссылку (менеджер/наблюдатель)
- Сменить роль / удалить

**/onboarding** — обновить: 
- Название проекта
- Добавить несколько магазинов (1-4, разных МП, разных юрлиц)

**/register** — поддержка инвайт-кода:
- Если ?invite=TOKEN — поле invite предзаполнено, после регистрации → membership
