# ДДС — журнал факта и отчёт: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Переделать `/fin-dds` в журнал фактических операций по счетам и статьям + отчёт ДДС «статьи × месяцы» с остатками, поверх единой таблицы денег `tenant.dds_movements`.

**Architecture:** Справочники `dds_accounts`/`dds_articles` (миграция 072) + колонки `account_id`/`account_to_id`/`article_key` в `dds_movements`. Чистое ядро `lib/dds.js` (статьи, правила правки, валидация, остатки, отчёт, срез по роли), чтение — `lib/ddsData.js`, запись — только `lib/paymentCalendarData.js` (расширяется). Роуты `dds` (журнал/отчёт/операции) и `dds-refs` (справочники/настройки). Календарь и план поступлений переходят на статьи из справочника и получают выбор счёта.

**Tech Stack:** Next.js 14 App Router, PostgreSQL + RLS (`lib/db.js`: `withTenant`, `tenantQuery`, `query`), `node:test`, inline-стили + `lib/palette.js`.

**Spec:** `docs/superpowers/specs/2026-10-17-dds-design.md`

## Global Constraints

- Только кабинет #1 для любых проб/записей. Чужие кабинеты не трогать (`SAAS_COLLECT_CABINETS=1`, клиентов нет).
- Ветка `feat/dds` от `master` в каталоге `/opt/agents/saas` (как у платёжного календаря). `git add` — только явный список файлов задачи, никогда `-A`/`.`. Неотслеживаемые `down/`, `scratchpad/` не трогать.
- Миграции идемпотентны, применяются `PGPASSFILE=/root/.pgpass-admin psql -h localhost -U postgres -d saas -v ON_ERROR_STOP=1 -f …`. Читать БД — `psql -h localhost -U saas_ro -d saas -Atc "…"`.
- Бэкап боевого файла перед правкой: `cp <file> /opt/agentsDB/backups/<name>.$(date +%Y%m%d_%H%M%S).bak` (новые файлы — без бэкапа).
- Пустой `catch {}` без `console.error` запрещён.
- Факт ДДС = `status='paid'`. `planned`/`archived` в журнал и отчёт не входят.
- Любой `INSERT`/`UPDATE`/`DELETE` по `tenant.dds_movements` — только в `lib/paymentCalendarData.js` (и в миграциях).
- Остатки, стартовые суммы, справочник счетов целиком и настройки ДДС — только `owner`; API не отдаёт их другим ролям (менеджер/наблюдатель получают счета как `{id, name, kind, is_archived}`).
- Даты `dds_movements.date` — `text` `YYYY-MM-DD`; «сегодня» — МСК (`new Date(Date.now()+3*3600e3).toISOString().slice(0,10)`). Деньги — `Math.round(x*100)/100`.
- Клиентские страницы: правила D1–D7 из `AGENTS.md` (компонент принимает `{ cabinetId }`, fetch в backticks к `/api/cabinets/${cabinetId}/…`, `await` у async, хуки до раннего `return`). Палитра — `C`, `soft` из `lib/palette.js`, никаких hex с альфой `${C.x}33`.
- Не запускать `next dev` в каталоге прода. Сборка/деплой — `npm run build && systemctl restart saas-web` (только в Task 8).
- Тесты: `node --test lib/__tests__/<file>.test.mjs`.

**Уточнения к спеке, принятые при планировании (вносятся в спеку в Task 1):**
1. `tenant.dds_recurring` тоже получает `article_key` — иначе повторы с пользовательской статьёй теряли бы её при материализации.
2. В отчёте строка «Изменение остатков вне статей» (только owner) = конец − начало − чистый поток колонки; ненулевая, когда в колонке стартует счёт или есть операции до старта счёта. Без неё «начало + поток = конец» врёт молча.
3. `type` у `dds_movements` получает CHECK `('income','expense','transfer')` (сейчас в БД только income/expense — проверено).
4. Статья `mp` (системная «Выплата МП (прочее)») только для поступлений: старые расходные «Возврат МП» → `other`.

```sql
-- 072_dds_accounts_articles.sql — ДДС: справочники счетов и статей, счёт/статья у движения, перевод
-- (17.10.2026, спека docs/superpowers/specs/2026-10-17-dds-design.md §2). Идемпотентно.
-- Устаревшие колонки dds_movements (category, income_type, account_from, account_to, source, nm_id)
-- код больше не читает и не пишет; platform пишет только receivePayout. Удаление — отдельной задачей.
BEGIN;

CREATE TABLE IF NOT EXISTS tenant.dds_accounts (
    cabinet_id      BIGINT        NOT NULL,
    id              BIGSERIAL     NOT NULL,
    name            TEXT          NOT NULL,
    kind            TEXT          NOT NULL DEFAULT 'other'
                    CHECK (kind IN ('bank_ip','card_person','cash','mp_wb','mp_ozon','other')),
    opening_balance NUMERIC(14,2) NOT NULL DEFAULT 0,
    opening_date    DATE          NOT NULL,
    sort            INTEGER       NOT NULL DEFAULT 0,
    is_archived     BOOLEAN       NOT NULL DEFAULT false,
    created_at      TIMESTAMPTZ   NOT NULL DEFAULT now(),
    updated_at      TIMESTAMPTZ   NOT NULL DEFAULT now(),
    PRIMARY KEY (cabinet_id, id)
);

CREATE TABLE IF NOT EXISTS tenant.dds_articles (
    cabinet_id  BIGINT      NOT NULL,
    key         TEXT        NOT NULL CHECK (key ~ '^[a-z][a-z0-9_]*$'),
    label       TEXT        NOT NULL,
    direction   TEXT        NOT NULL CHECK (direction IN ('income','expense')),
    activity    TEXT        NOT NULL CHECK (activity IN ('operating','investing','financing')),
    color       TEXT        NOT NULL DEFAULT 'line',
    sort        INTEGER     NOT NULL DEFAULT 0,
    is_system   BOOLEAN     NOT NULL DEFAULT false,
    is_archived BOOLEAN     NOT NULL DEFAULT false,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at  TIMESTAMPTZ NOT NULL DEFAULT now(),
    PRIMARY KEY (cabinet_id, key)
);

DO $$
DECLARE t TEXT;
BEGIN
  FOREACH t IN ARRAY ARRAY['dds_accounts','dds_articles'] LOOP
    EXECUTE format('ALTER TABLE tenant.%I ENABLE ROW LEVEL SECURITY', t);
    IF NOT EXISTS (SELECT 1 FROM pg_policies WHERE schemaname='tenant' AND tablename=t AND policyname='tenant_iso_'||t) THEN
      EXECUTE format($p$CREATE POLICY %I ON tenant.%I FOR ALL TO saas_app
                       USING (cabinet_id = current_setting('app.cabinet_id')::bigint)
                       WITH CHECK (cabinet_id = current_setting('app.cabinet_id')::bigint)$p$, 'tenant_iso_'||t, t);
    END IF;
    IF NOT EXISTS (SELECT 1 FROM pg_policies WHERE schemaname='tenant' AND tablename=t AND policyname='panel_local_ro_cab1') THEN
      EXECUTE format('CREATE POLICY panel_local_ro_cab1 ON tenant.%I FOR SELECT TO panel_local_ro USING (cabinet_id = 1)', t);
    END IF;
    EXECUTE format('GRANT SELECT, INSERT, UPDATE ON tenant.%I TO saas_app', t);
    EXECUTE format('GRANT SELECT ON tenant.%I TO panel_local_ro', t);
  END LOOP;
  EXECUTE 'GRANT USAGE, SELECT ON SEQUENCE tenant.dds_accounts_id_seq TO saas_app';
END $$;

ALTER TABLE tenant.dds_movements ADD COLUMN IF NOT EXISTS account_id    BIGINT;
ALTER TABLE tenant.dds_movements ADD COLUMN IF NOT EXISTS account_to_id BIGINT;
ALTER TABLE tenant.dds_movements ADD COLUMN IF NOT EXISTS article_key   TEXT;
ALTER TABLE tenant.dds_recurring ADD COLUMN IF NOT EXISTS article_key   TEXT;

DO $$ BEGIN
  IF NOT EXISTS (SELECT 1 FROM pg_constraint WHERE conname = 'dds_movements_type_chk') THEN
    ALTER TABLE tenant.dds_movements ADD CONSTRAINT dds_movements_type_chk
      CHECK (type IN ('income','expense','transfer'));
  END IF;
  IF NOT EXISTS (SELECT 1 FROM pg_constraint WHERE conname = 'dds_movements_transfer_chk') THEN
    ALTER TABLE tenant.dds_movements ADD CONSTRAINT dds_movements_transfer_chk
      CHECK ((type = 'transfer' AND article_key IS NULL AND account_id IS NOT NULL
              AND account_to_id IS NOT NULL AND account_id <> account_to_id)
          OR (type <> 'transfer' AND account_to_id IS NULL));
  END IF;
END $$;
CREATE INDEX IF NOT EXISTS ix_dds_movements_paid ON tenant.dds_movements (cabinet_id, date) WHERE status = 'paid';

-- Перенос category → article_key. Правило = articleKeyOf в lib/dds.js (менять вместе).
UPDATE tenant.dds_movements SET article_key = CASE
    WHEN type = 'income' THEN CASE
      WHEN source_kind = 'mp_payout' AND platform = 'wb'   THEN 'mp_wb'
      WHEN source_kind = 'mp_payout' AND platform = 'ozon' THEN 'mp_ozon'
      WHEN category IN ('Выплата МП','Возврат МП')         THEN 'mp'
      ELSE 'other_in' END
    ELSE CASE
      WHEN category IN ('Поставщик','Закупка') THEN 'supplier'
      WHEN category = 'Карго/логистика'       THEN 'cargo'
      WHEN category = 'Фулфилмент'            THEN 'ff'
      WHEN category = 'Налоги'                THEN 'tax'
      WHEN category IN ('Зарплата','ЗП')      THEN 'salary'
      WHEN category = 'Аренда'                THEN 'rent'
      WHEN category = 'Подписки'              THEN 'subs'
      WHEN category = 'Реклама'               THEN 'ads'
      ELSE 'other' END
  END
 WHERE article_key IS NULL AND type IN ('income','expense');

UPDATE tenant.dds_recurring SET article_key = CASE
    WHEN type = 'income' THEN CASE WHEN category IN ('Выплата МП','Возврат МП') THEN 'mp' ELSE 'other_in' END
    ELSE CASE
      WHEN category IN ('Поставщик','Закупка') THEN 'supplier'
      WHEN category = 'Карго/логистика'       THEN 'cargo'
      WHEN category = 'Фулфилмент'            THEN 'ff'
      WHEN category = 'Налоги'                THEN 'tax'
      WHEN category IN ('Зарплата','ЗП')      THEN 'salary'
      WHEN category = 'Аренда'                THEN 'rent'
      WHEN category = 'Подписки'              THEN 'subs'
      WHEN category = 'Реклама'               THEN 'ads'
      ELSE 'other' END
  END
 WHERE article_key IS NULL;

-- Стартовые счета — только кабинет #1, из последнего снимка «Баланса», если счетов ещё нет.
INSERT INTO tenant.dds_accounts (cabinet_id, name, kind, opening_balance, opening_date, sort)
SELECT 1,
       b.account_name || CASE WHEN b.subject = 'ip' THEN ' (ИП)' ELSE ' (физлицо)' END,
       CASE WHEN b.account_name = 'ВБ' THEN 'mp_wb' WHEN b.subject = 'ip' THEN 'bank_ip' ELSE 'card_person' END,
       b.amount, b.as_of_date::date,
       row_number() OVER (ORDER BY b.subject, b.id)
  FROM tenant.balance_accounts b
 WHERE b.cabinet_id = 1
   AND b.as_of_date = (SELECT max(as_of_date) FROM tenant.balance_accounts WHERE cabinet_id = 1)
   AND NOT EXISTS (SELECT 1 FROM tenant.dds_accounts WHERE cabinet_id = 1);

COMMIT;
```

export function balancesAt(accounts, movements, Dday) {
  const byId = new Map(accounts.map((a) => [Number(a.id), a]));
  const out = new Map([[NO_ACCOUNT, 0]]);
  for (const a of accounts) out.set(Number(a.id), Dday >= openDate(a) ? Number(a.opening_balance) || 0 : 0);

    }
  }

}

export function periodColumns(from, to, grain, today) {
  const cols = [];
  if (grain === "week") {
    for (let mon = addDays(from, 1 - isoDow(from)); mon <= to; mon = addDays(mon, 7)) {
      const f = mon < from ? from : mon, sun = addDays(mon, 6), t = sun > to ? to : sun;
      cols.push({ key: mon, from: f, to: t, label: `${f.slice(8)}.${f.slice(5, 7)}–${t.slice(8)}.${t.slice(5, 7)}`, partial: t >= today });
    }
    return cols;
  }
  let [y, m] = from.slice(0, 7).split("-").map(Number);
  for (;;) {
    const mm = String(m).padStart(2, "0");
    const mFrom = `${y}-${mm}-01`;
    if (mFrom > to) break;
    const mTo = `${y}-${mm}-${String(lastDay(y, m)).padStart(2, "0")}`;
    const f = mFrom < from ? from : mFrom, t = mTo > to ? to : mTo;
    cols.push({ key: `${y}-${mm}`, from: f, to: t, label: `${MONTHS[m - 1]} ${y}`, partial: t >= today });
    m += 1; if (m > 12) { m = 1; y += 1; }
  }
  return cols;
}

// Report: { columns, groups[{activity,label,income[],expense[],incomeTotal[],expenseTotal[],net[],netTotal}],
//   netFlow[], netFlowTotal, opening[], openingTotal, closing[], closingTotal, adjust[], adjustTotal,
//   byAccount[{id,name,closing[]}] }. Строки статей: {key,label,color,cells[],total}; расходы — положительные числа.
export function buildReport({ articles, accounts, movements, from, to, grain, today }) {
  const columns = periodColumns(from, to, grain, today);
  const n = columns.length;
  const colOf = (date) => columns.findIndex((c) => date >= c.from && date <= c.to);
  const artMap = new Map(articles.map((a) => [a.key, a]));
  const cells = new Map(); // key → {art, cells[]}
  for (const m of movements) {
    if (!isFact(m) || m.type === "transfer") continue;
    const i = colOf(m.date);
    if (i < 0) continue;
    const key = m.article_key || (m.type === "income" ? "other_in" : "other");
    if (!cells.has(key)) {
      const art = artMap.get(key) || { key, label: key, direction: m.type, activity: "operating", color: "line", sort: 9999 };
      cells.set(key, { art, cells: Array(n).fill(0) });
    }
    cells.get(key).cells[i] = r2(cells.get(key).cells[i] + (Number(m.amount) || 0));
  }
  const rowsOf = (activity, direction) => [...cells.values()]
    .filter((x) => x.art.activity === activity && x.art.direction === direction)
    .sort((a, b) => (a.art.sort ?? 0) - (b.art.sort ?? 0) || a.art.label.localeCompare(b.art.label))
    .map((x) => ({ key: x.art.key, label: x.art.label, color: x.art.color, cells: x.cells, total: r2(x.cells.reduce((s, v) => s + v, 0)) }));
  const colSum = (rows) => Array.from({ length: n }, (_, i) => r2(rows.reduce((s, r) => s + r.cells[i], 0)));
  const groups = [];
  for (const a of ACTIVITIES) {
    const income = rowsOf(a.key, "income"), expense = rowsOf(a.key, "expense");
    if (!income.length && !expense.length) continue;
    const incomeTotal = colSum(income), expenseTotal = colSum(expense);
    const net = incomeTotal.map((v, i) => r2(v - expenseTotal[i]));
    groups.push({ activity: a.key, label: a.label, income, expense, incomeTotal, expenseTotal, net, netTotal: r2(net.reduce((s, v) => s + v, 0)) });
  }
  const netFlow = Array.from({ length: n }, (_, i) => r2(groups.reduce((s, g) => s + g.net[i], 0)));
  const startMaps = columns.map((c) => balancesAt(accounts, movements, c.from));
  const endMaps = columns.map((c) => balancesAt(accounts, movements, addDays(c.to, 1)));
  const opening = startMaps.map(sumMap), closing = endMaps.map(sumMap);
  const adjust = closing.map((c, i) => r2(c - opening[i] - netFlow[i]));
  const byAccount = [...accounts.map((a) => ({ id: Number(a.id), name: a.name })), { id: NO_ACCOUNT, name: "Счёт не указан" }]
    .map((a) => ({ ...a, closing: endMaps.map((m) => m.get(a.id) || 0) }))
    .filter((a) => a.id !== NO_ACCOUNT || a.closing.some((v) => v !== 0));
  return {
    columns, groups, netFlow, netFlowTotal: r2(netFlow.reduce((s, v) => s + v, 0)),
    opening, openingTotal: opening[0] ?? 0, closing, closingTotal: closing[n - 1] ?? 0,
    adjust, adjustTotal: r2(adjust.reduce((s, v) => s + v, 0)), byAccount,
  };
}

export function journalTotals(rows) {
  let income = 0, expense = 0;
  for (const r of rows) {
    if (r.type === "income") income += Number(r.amount) || 0;
    else if (r.type === "expense") expense += Number(r.amount) || 0;
  }
  return { income: r2(income), expense: r2(expense), net: r2(income - expense) };
}

// Фильтры журнала. account: id | 'none'; source: manual|recurring|purchase|mp_payout|transfer.
function journalWhere({ from, to, account, article, type, source, q }) {
  const conds = ["status = 'paid'"], params = [];
  const p = (v) => { params.push(v); return `$${params.length}`; };
  if (ISO.test(from || "")) conds.push(`date >= ${p(from)}`);
  if (ISO.test(to || "")) conds.push(`date <= ${p(to)}`);
  if (account === "none") conds.push(`account_id IS NULL AND type <> 'transfer'`);
  else if (Number(account) > 0) { const x = p(Number(account)); conds.push(`(account_id = ${x} OR account_to_id = ${x})`); }
  if (article) conds.push(`article_key = ${p(String(article))}`);
  if (["income", "expense", "transfer"].includes(type)) conds.push(`type = ${p(type)}`);
  if (source === "transfer") conds.push(`type = 'transfer'`);
  else if (["manual", "recurring", "purchase", "mp_payout"].includes(source)) conds.push(`source_kind = ${p(source)} AND type <> 'transfer'`);
  if (q && String(q).trim()) { const x = p(`%${String(q).trim()}%`); conds.push(`(counterparty ILIKE ${x} OR description ILIKE ${x})`); }
  return { where: conds.join(" AND "), params };
}

export const PAGE_SIZE = 100;
export async function loadJournal(f) {
  const { where, params } = journalWhere(f);
  const page = Math.max(1, Number(f.page) || 1);
  const items = await tenantQuery(
    `SELECT id::int AS id, date, type, amount::float8 AS amount, article_key, account_id::int AS account_id,
            account_to_id::int AS account_to_id, counterparty, description, source_kind, source_ref, date_locked
       FROM tenant.dds_movements WHERE ${where}
      ORDER BY date DESC, id DESC LIMIT ${PAGE_SIZE} OFFSET ${(page - 1) * PAGE_SIZE}`, params);
  const agg = (await tenantQuery(
    `SELECT COUNT(*)::int AS n,
            COALESCE(SUM(amount) FILTER (WHERE type = 'income'), 0)::float8 AS income,
            COALESCE(SUM(amount) FILTER (WHERE type = 'expense'), 0)::float8 AS expense
       FROM tenant.dds_movements WHERE ${where}`, params))[0];
  const noAcc = (await tenantQuery(
    `SELECT COUNT(*)::int AS n FROM tenant.dds_movements WHERE status = 'paid' AND type <> 'transfer' AND account_id IS NULL`))[0];
  return {
    items, total: agg.n, page, pageSize: PAGE_SIZE,
    totals: { income: r2(agg.income), expense: r2(agg.expense), net: r2(agg.income - agg.expense) },
    noAccountCount: noAcc.n,
  };
}

async function factMovementsUpTo(to) {

}

}

export async function saveArticle(b) {
  const label = String(b.label || "").trim();
  if (!label) throw httpError("название статьи обязательно");
  if (b.color != null && !COLORS.includes(b.color)) throw httpError("цвет статьи");
  if (b.key) {
    const cur = (await tenantQuery(`SELECT key, is_system FROM tenant.dds_articles WHERE key = $1 FOR UPDATE`, [b.key]))[0];
    if (!cur) throw httpError(`статья ${b.key} не найдена`, 404);
    // у системной меняются только название, цвет и порядок; направление не меняется ни у какой
    const activity = !cur.is_system && ["operating", "investing", "financing"].includes(b.activity) ? b.activity : null;
    await tenantQuery(
      `UPDATE tenant.dds_articles SET label = $1, color = COALESCE($2, color), sort = COALESCE($3, sort),
          activity = COALESCE($4, activity), updated_at = now() WHERE key = $5`,
      [label, b.color ?? null, b.sort != null ? Number(b.sort) : null, activity, b.key]);
    return b.key;
  }
  if (!["income", "expense"].includes(b.direction)) throw httpError("direction: income|expense");
  if (!["operating", "investing", "financing"].includes(b.activity)) throw httpError("activity: operating|investing|financing");
  const r = await tenantQuery(
    `INSERT INTO tenant.dds_articles (cabinet_id, key, label, direction, activity, color, sort, is_system)
     SELECT current_setting('app.cabinet_id')::bigint,
            'u_' || (COALESCE(MAX(substring(key from 3)::int), 0) + 1), $1, $2, $3, $4, COALESCE($5, 1000), false
       FROM tenant.dds_articles WHERE key ~ '^u_[0-9]+$'
     RETURNING key`,
    [label, b.direction, b.activity, b.color || "line", b.sort != null ? Number(b.sort) : null]);
  return r[0].key;
}

const KINDS = ["bank_ip", "card_person", "cash", "mp_wb", "mp_ozon", "other"];
export async function saveAccount(b) {

        WHERE id=$6 RETURNING id::int AS id`, [...vals, Number(b.id)]);

}

}

export async function updateMovement(id, b) {
  const cur = (await tenantQuery(`SELECT * FROM tenant.dds_movements WHERE id = $1 AND status <> 'archived' FOR UPDATE`, [id]))[0];
  if (!cur) throw httpError(`платёж id=${id} не найден`, 404);
  if (b.date !== undefined && b.date !== null && !/^\d{4}-\d{2}-\d{2}$/.test(String(b.date))) throw httpError("дата YYYY-MM-DD");
  const rules = editRules(cur);
  const refs = await loadRefs();
  const has = (k) => b[k] !== undefined;
  const next = {
    type: cur.type,
    date: has("date") && b.date ? b.date : cur.date,
    amount: rules.amount && has("amount") ? b.amount : 1, // сумму без права правки не валидируем (выплата бывает ≤ 0)
    article_key: rules.article && has("article_key") ? (b.article_key || null) : cur.article_key,
    account_id: has("account_id") ? (b.account_id === "" || b.account_id === null ? null : Number(b.account_id)) : (cur.account_id != null ? Number(cur.account_id) : null),
    account_to_id: cur.type === "transfer" && has("account_to_id") ? Number(b.account_to_id) : (cur.account_to_id != null ? Number(cur.account_to_id) : null),
  };
  const err = validateDdsMovement(next, refs, { allowArchived: [cur.account_id, cur.account_to_id] });
  if (err) throw httpError(err);
  const detach = cur.source_kind === "recurring" && (has("amount") || has("article_key") || has("counterparty"));
  await tenantQuery(
    `UPDATE tenant.dds_movements SET
        date = $1, date_locked = date_locked OR ($1 <> date AND source_kind IN ('purchase','mp_payout')),
        amount = CASE WHEN $2::boolean THEN $3::numeric ELSE amount END,
        amount_planned = CASE WHEN $2::boolean AND status = 'planned' THEN $3::numeric ELSE amount_planned END,
        article_key = $4, account_id = $5, account_to_id = $6,
        counterparty = CASE WHEN $7::boolean THEN $8 ELSE counterparty END,
        description = COALESCE($9, description),
        source_kind = CASE WHEN $10::boolean THEN 'manual' ELSE source_kind END,
        updated_at = now()
      WHERE id = $11`,
    [next.date, rules.amount && has("amount"), rules.amount && has("amount") ? num(b.amount) : 0,
     next.article_key, next.account_id, next.account_to_id,
     rules.counterparty && has("counterparty"), b.counterparty || null,
     has("description") ? (b.description ?? "") : null, detach, id]);
}

// /fin-dds — ДДС: журнал факта, отчёт, счета, статьи (17.10.2026, спека docs/superpowers/specs/2026-10-17-dds-design.md §5).
import { useCallback, useEffect, useState } from "react";

import FinanceMoneyTabs from "../fin-calendar/FinanceMoneyTabs.jsx";

            border: `1px solid ${tab === k ? C.accent : C.line}`, background: tab === k ? C.accent : "transparent", color: tab === k ? "var(--accentInk)" : C.ink }}>{l}</button>
        ))}
      </div>
      {err && <div style={{ color: C.neg, marginBottom: 12 }}>⚠ {err}</div>}
      {refs && tab === "journal" && <JournalTab cabinetId={cabinetId} refs={refs} initial={Object.fromEntries(sp.entries())} />}
      {refs && tab === "report" && <ReportTab cabinetId={cabinetId} refs={refs} onDrill={(f) => go("journal", f)} />}
      {refs && tab === "accounts" && refs.isOwner && <AccountsTab cabinetId={cabinetId} refs={refs} onChanged={loadRefs} />}
