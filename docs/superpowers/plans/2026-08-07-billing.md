# Оплата подписки — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Клиент оплачивает доступ к проекту через ЮKassa на 1, 3 или 12 месяцев; неоплаченный кабинет закрывается через 3 дня после истечения (спека `docs/superpowers/specs/2026-08-07-billing-design.md`).

**Architecture:** Состояние доступа не хранится, а вычисляется функцией `cabinetAccess()` из двух дат кабинета (`trial_ends_at`, `paid_until`). Деньги учитываются журналом `billing.payments`, `paid_until` — производная от него. Общение с ЮKassa изолировано в `lib/yookassa.js`; пока боевых ключей нет, работает мок-режим (`SAAS_YOOKASSA_MOCK=1`) — как «почтовая раковина» в фазе 3: флоу целиком проверяется смоуком, при появлении ключей флаг убирается, код не меняется. Зачисление — только по вебхуку с обязательной перепроверкой платежа через API провайдера; страховка от потерянных уведомлений — часовой скрипт сверки.

**Tech Stack:** Next.js 14 (app router), PostgreSQL (миграции `db/migrations/0NN_*.sql`), node:crypto, глобальный `fetch` (Node 24), systemd-таймер, Caddy (проставляет `X-Forwarded-For`).

## Global Constraints

- Прод-хост = репозиторий `/opt/agents/saas`, ветка master, remote нет.
- **ЗАПРЕЩЕНО `next dev` в каталоге прода** (затирает `.next`, роняет прод — правило AGENTS.md). Верификация: `npm run build && (npx next start -p 3210 &)`, после — убить процесс **только на 3210** (на 3200 живёт прод).
- Деплой (только задача 6): `npm run build && systemctl restart saas-web`.
- Backup боевого файла перед правкой → `/opt/agentsDB/backups/<имя>.bak-2026-08-07b`.
- Верификаторы: `scripts/smoke-billing.mjs` (задача 2) + регресс `smoke-auth-phase3.mjs`, `phase2`, `phase1`, `phase0`. Все сами готовят и чистят данные; **тестовых записей в боевой БД оставаться не должно** (`auth.users` с `%@smoke.test`, `billing.plans` с `code LIKE 'smoke-%'`, их платежи и кабинеты — ноль после прогона). `CLEANUP FAIL` = провал.
- Миграции идемпотентны, нумерация с `034_`; новым таблицам — явный `GRANT` для `saas_app` (роль приложения, DDL и DELETE у неё нет).
- **Сумма платежа никогда не приходит от клиента** — только код плана; цену сервер берёт из `billing.plans`.
- **Доступ открывается только после перепроверки платежа через API ЮKassa**, никогда по возврату из браузера.
- Деньги: `NUMERIC(10,2)`, в рублях; в JS сравнивать через строки/целые копейки, не через float.
- Комментарии и UI-тексты — по-русски. Каждая задача — отдельный коммит с префиксом из задачи.

```sql
-- trial_ends_at и paid_until (lib/billing.js). billing.payments — журнал

ALTER TABLE auth.cabinets ADD COLUMN IF NOT EXISTS paid_until TIMESTAMPTZ;

CREATE SCHEMA IF NOT EXISTS billing;
GRANT USAGE ON SCHEMA billing TO saas_app;

-- Тарифы. Цены задаёт владелец INSERT'ом при внедрении: в коде их нет,
-- менять можно без пересборки панели.
CREATE TABLE IF NOT EXISTS billing.plans (
  code       TEXT PRIMARY KEY,
  months     INT NOT NULL CHECK (months > 0),
  price_rub  NUMERIC(10,2) NOT NULL CHECK (price_rub > 0),
  title      TEXT NOT NULL,
  is_active  BOOLEAN NOT NULL DEFAULT true,
  sort       INT NOT NULL DEFAULT 0
);

-- Журнал платежей. payment_id — идентификатор ЮKassa, он же ключ
-- идемпотентности: повторное уведомление по тому же платежу не продлит
-- подписку второй раз.
CREATE TABLE IF NOT EXISTS billing.payments (
  payment_id        TEXT PRIMARY KEY,
  cabinet_id        BIGINT NOT NULL REFERENCES auth.cabinets(cabinet_id) ON DELETE CASCADE,
  user_id           BIGINT NOT NULL REFERENCES auth.users(user_id),
  plan_code         TEXT NOT NULL,
  months            INT NOT NULL,
  amount_rub        NUMERIC(10,2) NOT NULL,
  status            TEXT NOT NULL DEFAULT 'pending'
                    CHECK (status IN ('pending','succeeded','canceled')),
  paid_until_before TIMESTAMPTZ,
  paid_until_after  TIMESTAMPTZ,
  raw               JSONB,
  created_at        TIMESTAMPTZ NOT NULL DEFAULT now(),
  updated_at        TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX IF NOT EXISTS payments_cabinet_idx ON billing.payments (cabinet_id, created_at DESC);
CREATE INDEX IF NOT EXISTS payments_pending_idx ON billing.payments (created_at) WHERE status = 'pending';

GRANT SELECT ON billing.plans TO saas_app;
GRANT SELECT, INSERT, UPDATE ON billing.payments TO saas_app;
```

```js
// lib/billing.js — состояние доступа кабинета и тарифы.
// Состояние НЕ хранится в БД: две даты (trial_ends_at, paid_until) — источник
// истины, всё остальное выводится здесь. Одна функция на всю панель, чтобы
// условие «оплачено или нет» не расползлось копиями по коду.
import { query } from './db.js';

export const GRACE_DAYS = Number(process.env.SAAS_GRACE_DAYS) || 3;

const DAY_MS = 86400000;
const toDate = (v) => (v ? new Date(v) : null);

// state: trial — идёт пробный период; active — оплачено; grace — срок вышел,
// но отсрочка ещё идёт (полный доступ); locked — доступ закрыт.
export function cabinetAccess(cabinet, now = new Date()) {
  const trial = toDate(cabinet?.trial_ends_at);
  const paid = toDate(cabinet?.paid_until);
  const until = !trial && !paid ? null : new Date(Math.max(trial?.getTime() || 0, paid?.getTime() || 0));
  const graceUntil = until ? new Date(until.getTime() + GRACE_DAYS * DAY_MS) : null;
  const daysLeft = until ? Math.ceil((until.getTime() - now.getTime()) / DAY_MS) : 0;

  if (!until) return { state: 'locked', until: null, daysLeft: 0, graceUntil: null };
  if (until.getTime() > now.getTime()) {
    // Оплата важнее триала: если платили — состояние active, даже когда
    // триал ещё формально не кончился.
    return { state: paid && paid.getTime() >= (trial?.getTime() || 0) ? 'active' : 'trial', until, daysLeft, graceUntil };
  }
  if (graceUntil.getTime() > now.getTime()) return { state: 'grace', until, daysLeft, graceUntil };
  return { state: 'locked', until, daysLeft, graceUntil };
}

// Новая дата окончания при оплате: продлеваем от большей из «сейчас» и
// текущего срока — оплативший заранее не теряет остаток, вернувшийся после
// блокировки не платит за прошедшее.
export function extendPaidUntil(cabinet, months, now = new Date()) {
  const { until } = cabinetAccess(cabinet, now);
  const base = until && until.getTime() > now.getTime() ? new Date(until) : new Date(now);
  const next = new Date(base);
  next.setMonth(next.getMonth() + months);
  return next;
}

export async function activePlans() {
  return query(
    `SELECT code, months, price_rub, title FROM billing.plans
     WHERE is_active = true ORDER BY sort, months`
  );
}

export async function planByCode(code) {
  const rows = await query(
    `SELECT code, months, price_rub, title FROM billing.plans
     WHERE code = $1 AND is_active = true`,
    [String(code || '')]
  );
  return rows[0] || null;
}
```

```js
#!/usr/bin/env node
// scripts/smoke-billing.mjs — смоук оплаты подписки.
// Использование: SAAS_YOOKASSA_MOCK=1 node scripts/smoke-billing.mjs [base_url]
// Требует сервер, поднятый с SAAS_YOOKASSA_MOCK=1 (без боевых ключей ЮKassa).
// Пишет в БД только свои записи (*@smoke.test, планы smoke-*) и сам их чистит.
import pg from 'pg';
import { readFileSync } from 'node:fs';
import { homedir } from 'node:os';

const { types } = pg;
types.setTypeParser(20, (v) => v === null ? null : Number(v));
types.setTypeParser(1700, (v) => v === null ? null : Number(v));

const BASE = process.argv[2] || 'http://localhost:3210';
for (const line of readFileSync(new URL('../.env.local', import.meta.url), 'utf8').split('\n')) {
  const m = line.match(/^([A-Z_0-9]+)=(.*)$/);
  if (m && !process.env[m[1]]) process.env[m[1]] = m[2];
}
const pgpass = readFileSync(`${homedir()}/.pgpass`, 'utf8').split('\n')
  .map(l => l.trim()).filter(l => l && !l.startsWith('#')).map(l => l.split(':'))
  .find(p => p[3] === 'postgres');
if (!pgpass) { console.error('нет строки postgres в ~/.pgpass'); process.exit(2); }
const pool = new pg.Pool({
  host: 'localhost', port: Number(pgpass[1]) || 5432,
  database: process.env.SAAS_DB || 'saas', user: 'postgres', password: pgpass[4],
});
const q = (sql, p) => pool.query(sql, p).then(r => r.rows);

let failed = 0, cleanupFailed = false;
const check = (name, cond, extra = '') => {
  console.log(`${cond ? 'PASS' : 'FAIL'}  ${name}${cond ? '' : '  ' + extra}`);
  if (!cond) failed++;
};
async function api(method, path, { body, cookie } = {}) {
  const res = await fetch(BASE + path, {
    method,
    headers: { 'Content-Type': 'application/json', ...(cookie ? { cookie } : {}) },
    body: body ? JSON.stringify(body) : undefined,
    redirect: 'manual',
  });
  let json = null;
  try { json = await res.json(); } catch {}
  return { status: res.status, json, cookie: (res.headers.get('set-cookie') || '').split(';')[0] || cookie };
}
const reg = (email) => api('POST', '/api/auth/register', { body: { email, password: 'smoke-pass-123' } });

const run = Date.now();
const PLAN = `smoke-1m-${run}`;
let cabinetId = null, ownerCookie = null, ownerId = null, viewerCookie = null, paymentId = null;

try {
  if (process.env.SAAS_YOOKASSA_MOCK !== '1') {
    console.error('Смоук требует SAAS_YOOKASSA_MOCK=1 (и сервер, поднятый с тем же флагом)');
    process.exit(2);
  }

  // ── Подготовка: тарифный план, владелец с кабинетом ──
  await q(`INSERT INTO billing.plans (code, months, price_rub, title, sort)
           VALUES ($1, 1, 100.00, 'Смоук-месяц', 999)`, [PLAN]);
  const owner = await reg(`billowner-${run}@smoke.test`);
  ownerCookie = owner.cookie; ownerId = owner.json?.user?.user_id;
  const onb = await api('POST', '/api/onboarding/start', {
    cookie: ownerCookie, body: { display_name: `smoke-bill-${run}`, marketplaces: ['wb'] },
  });
  cabinetId = onb.json?.cabinet?.cabinet_id;
  check('подготовка: кабинет создан', !!cabinetId, JSON.stringify(onb.json));

  // ── 1. Состояние на триале ──
  const st1 = await api('GET', `/api/cabinets/${cabinetId}/billing`, { cookie: ownerCookie });
  check('состояние: trial', st1.status === 200 && st1.json?.state === 'trial', `${st1.status} ${JSON.stringify(st1.json)}`);
  check('...планы отдаются', Array.isArray(st1.json?.plans) && st1.json.plans.some(p => p.code === PLAN), JSON.stringify(st1.json?.plans));

  // ── 2. Сумма берётся с сервера, а не из запроса ──
  const pay = await api('POST', `/api/cabinets/${cabinetId}/billing/pay`, {
    cookie: ownerCookie, body: { plan_code: PLAN, amount_rub: 1 },
  });
  check('создание платежа: 200 + ссылка', pay.status === 200 && typeof pay.json?.confirmation_url === 'string', `${pay.status} ${JSON.stringify(pay.json)}`);
  paymentId = pay.json?.payment_id;
  const payRow = paymentId ? (await q(`SELECT amount_rub, status, months FROM billing.payments WHERE payment_id = $1`, [paymentId]))[0] : null;
  check('...сумма из плана (100), а не из тела запроса', Number(payRow?.amount_rub) === 100, JSON.stringify(payRow));
  check('...статус pending', payRow?.status === 'pending', String(payRow?.status));

  // ── 3. Возврат из браузера сам по себе доступ не открывает ──
  const beforeWebhook = (await q(`SELECT paid_until FROM auth.cabinets WHERE cabinet_id = $1`, [cabinetId]))[0];
  check('до вебхука paid_until пуст', beforeWebhook?.paid_until === null, String(beforeWebhook?.paid_until));

  // ── 4. Зачисление по вебхуку ──
  const hook1 = await api('POST', `/api/billing/webhook/${process.env.SAAS_YOOKASSA_WEBHOOK_SECRET}`, {
    body: { event: 'payment.succeeded', object: { id: paymentId } },
  });
  check('вебхук принят: 200', hook1.status === 200, `${hook1.status} ${JSON.stringify(hook1.json)}`);
  const afterHook = (await q(`SELECT paid_until FROM auth.cabinets WHERE cabinet_id = $1`, [cabinetId]))[0];
  check('paid_until сдвинут', !!afterHook?.paid_until, String(afterHook?.paid_until));
  const payRow2 = (await q(`SELECT status, paid_until_after FROM billing.payments WHERE payment_id = $1`, [paymentId]))[0];
  check('...платёж succeeded с записанной датой', payRow2?.status === 'succeeded' && !!payRow2?.paid_until_after, JSON.stringify(payRow2));

  // ── 5. Повторный вебхук не продлевает второй раз ──
  await api('POST', `/api/billing/webhook/${process.env.SAAS_YOOKASSA_WEBHOOK_SECRET}`, {
    body: { event: 'payment.succeeded', object: { id: paymentId } },
  });
  const afterHook2 = (await q(`SELECT paid_until FROM auth.cabinets WHERE cabinet_id = $1`, [cabinetId]))[0];
  check('повторный вебхук не продлил', String(afterHook2?.paid_until) === String(afterHook?.paid_until), `${afterHook?.paid_until} → ${afterHook2?.paid_until}`);

  // ── 6. Неверный секрет в URL вебхука отклоняется ──
  const badHook = await api('POST', `/api/billing/webhook/wrong-secret-000`, {
    body: { event: 'payment.succeeded', object: { id: paymentId } },
  });
  check('вебхук с чужим секретом: 404', badHook.status === 404, `got ${badHook.status}`);

  // ── 7. Состояние стало active ──
  const st2 = await api('GET', `/api/cabinets/${cabinetId}/billing`, { cookie: ownerCookie });
  check('состояние: active', st2.json?.state === 'active', JSON.stringify(st2.json?.state));
  check('...платёж виден в истории', Array.isArray(st2.json?.payments) && st2.json.payments.length === 1, JSON.stringify(st2.json?.payments));

  // ── 8. Наблюдатель не может платить ──
  const viewer = await reg(`billviewer-${run}@smoke.test`);
  viewerCookie = viewer.cookie;
  await q(`INSERT INTO auth.memberships (user_id, cabinet_id, role) VALUES ($1, $2, 'viewer')`, [viewer.json?.user?.user_id, cabinetId]);
  const viewerPay = await api('POST', `/api/cabinets/${cabinetId}/billing/pay`, { cookie: viewerCookie, body: { plan_code: PLAN } });
  check('наблюдатель не может оплатить: 403', viewerPay.status === 403, `got ${viewerPay.status}`);
  const viewerSee = await api('GET', `/api/cabinets/${cabinetId}/billing`, { cookie: viewerCookie });
  check('...но состояние видит: 200', viewerSee.status === 200, `got ${viewerSee.status}`);

  // ── 9. Блокировка просроченного кабинета ──
  await q(`UPDATE auth.cabinets SET trial_ends_at = now() - interval '30 days', paid_until = now() - interval '10 days' WHERE cabinet_id = $1`, [cabinetId]);
  const locked = await api('GET', `/api/cabinets/${cabinetId}/members`, { cookie: ownerCookie });
  check('кабинетный API заблокирован: 402', locked.status === 402 && locked.json?.code === 'subscription_required', `${locked.status} ${JSON.stringify(locked.json)}`);
  const billingStillOpen = await api('GET', `/api/cabinets/${cabinetId}/billing`, { cookie: ownerCookie });
  check('биллинговый API доступен при блокировке', billingStillOpen.status === 200 && billingStillOpen.json?.state === 'locked', `${billingStillOpen.status} ${JSON.stringify(billingStillOpen.json?.state)}`);
  const payWhenLocked = await api('POST', `/api/cabinets/${cabinetId}/billing/pay`, { cookie: ownerCookie, body: { plan_code: PLAN } });
  check('оплатить из блокировки можно', payWhenLocked.status === 200, `got ${payWhenLocked.status}`);

  // ── 10. Отсрочка: срок вышел вчера — доступ ещё есть ──
  await q(`UPDATE auth.cabinets SET paid_until = now() - interval '1 day' WHERE cabinet_id = $1`, [cabinetId]);
  const graceCall = await api('GET', `/api/cabinets/${cabinetId}/members`, { cookie: ownerCookie });
  check('в отсрочке доступ сохраняется: 200', graceCall.status === 200, `got ${graceCall.status}`);
} finally {
  const cf = (e) => { console.error('CLEANUP FAIL:', e.message); cleanupFailed = true; };
  if (cabinetId) {
    await q(`DELETE FROM billing.payments WHERE cabinet_id = $1`, [cabinetId]).catch(cf);
    await q(`DELETE FROM jobs.collect_jobs WHERE cabinet_id = $1`, [cabinetId]).catch(cf);
    await q(`DELETE FROM auth.memberships WHERE cabinet_id = $1`, [cabinetId]).catch(cf);
    await q(`DELETE FROM auth.cabinets WHERE cabinet_id = $1`, [cabinetId]).catch(cf);
```

```js
// lib/yookassa.js — единственное место, где панель общается с ЮKassa.
// Пока боевых ключей нет, работает мок (SAAS_YOOKASSA_MOCK=1): платёж
// «создаётся» локально, а подтверждается страницей-заглушкой. Флоу целиком
// проверяется смоуком; при появлении ключей флаг убирается, код не меняется.
import crypto from 'node:crypto';

const API = 'https://api.yookassa.ru/v3/payments';

export function isMock() {
  return process.env.SAAS_YOOKASSA_MOCK === '1' && !process.env.SAAS_YOOKASSA_SHOP_ID;
}

export function isConfigured() {
  return isMock() || Boolean(process.env.SAAS_YOOKASSA_SHOP_ID && process.env.SAAS_YOOKASSA_SECRET_KEY);
}

function authHeader() {
  const raw = `${process.env.SAAS_YOOKASSA_SHOP_ID}:${process.env.SAAS_YOOKASSA_SECRET_KEY}`;
  return 'Basic ' + Buffer.from(raw).toString('base64');
}

// Сумма всегда строкой с двумя знаками: float в деньгах недопустим.
const money = (rub) => Number(rub).toFixed(2);

export async function createPayment({ amountRub, description, returnUrl, idempotenceKey, customerEmail }) {
  if (isMock()) {
    const id = 'mock-' + crypto.randomUUID();
    const base = process.env.NEXT_PUBLIC_URL || 'https://sysell.ru';
    return { id, status: 'pending', confirmation_url: `${base}/billing/mock?payment=${id}` };
  }
  const body = {
    amount: { value: money(amountRub), currency: 'RUB' },
    capture: true,
    confirmation: { type: 'redirect', return_url: returnUrl },
    description,
    receipt: {
      customer: { email: customerEmail },
      items: [{
        description,
        quantity: '1.00',
        amount: { value: money(amountRub), currency: 'RUB' },
        vat_code: Number(process.env.SAAS_YOOKASSA_VAT_CODE) || 1, // 1 = без НДС
        payment_mode: 'full_payment',
        payment_subject: 'service',
      }],
    },
  };
  const res = await fetch(API, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Idempotence-Key': idempotenceKey,
      Authorization: authHeader(),
    },
    body: JSON.stringify(body),
  });
  const json = await res.json().catch(() => ({}));
  if (!res.ok) {
    throw new Error(`ЮKassa ${res.status}: ${json?.description || 'ошибка создания платежа'}`);
  }
  return { id: json.id, status: json.status, confirmation_url: json.confirmation?.confirmation_url };
}

// Перепроверка платежа у провайдера. Единственный источник правды о том,
// прошли ли деньги: телу вебхука и возврату из браузера доверять нельзя.
export async function getPayment(id) {
  if (isMock()) {
    // В моке правду хранит наша же таблица: страница-заглушка помечает
    // платёж как оплаченный в raw.mock_status.
    const { query } = await import('./db.js');
    const rows = await query(`SELECT amount_rub, raw FROM billing.payments WHERE payment_id = $1`, [id]);
    if (!rows.length) return null;
    const status = rows[0].raw?.mock_status || 'pending';
    return { id, status, amount_rub: rows[0].amount_rub, paid: status === 'succeeded' };
  }
  const res = await fetch(`${API}/${encodeURIComponent(id)}`, {
    headers: { Authorization: authHeader() },
  });
  const json = await res.json().catch(() => ({}));
  if (!res.ok) throw new Error(`ЮKassa ${res.status}: ${json?.description || 'ошибка запроса платежа'}`);
  return { id: json.id, status: json.status, amount_rub: json.amount?.value, paid: json.status === 'succeeded' && json.paid === true };
}
```

```js
// lib/billing-credit.js — зачисление платежа. Одна точка входа и для вебхука,
// и для скрипта сверки: логика продления не должна существовать в двух копиях.
import { getPool } from './db.js';
import { getPayment } from './yookassa.js';
import { extendPaidUntil } from './billing.js';

// Идемпотентно: продлевает подписку не более одного раза на платёж.
// Возвращает { ok, reason?, paid_until? }.
export async function creditPayment(paymentId) {
  const provider = await getPayment(paymentId);
  if (!provider) return { ok: false, reason: 'платёж не найден у провайдера' };
  if (!provider.paid) return { ok: false, reason: `платёж не оплачен (${provider.status})` };

  const client = await getPool().connect();
  try {
    await client.query('BEGIN');
    // Блокируем строку платежа: два одновременных уведомления не пройдут оба.
    const rows = await client.query(
      `SELECT payment_id, cabinet_id, months, amount_rub, status
         FROM billing.payments WHERE payment_id = $1 FOR UPDATE`,
      [paymentId]
    );
    if (!rows.rowCount) { await client.query('ROLLBACK'); return { ok: false, reason: 'платёж не найден в журнале' }; }
    const p = rows.rows[0];
    if (p.status === 'succeeded') { await client.query('ROLLBACK'); return { ok: true, already: true }; }

    // Сумма провайдера обязана совпасть с нашей ценой. Не совпало — денег не
    // зачисляем вовсе: это ручной разбор, а не повод угадывать.
    if (Number(provider.amount_rub) !== Number(p.amount_rub)) {
      await client.query(
        `UPDATE billing.payments SET status = 'succeeded', updated_at = now(),
                raw = coalesce(raw,'{}'::jsonb) || $2::jsonb
          WHERE payment_id = $1`,
        [paymentId, JSON.stringify({ mismatch: { expected: p.amount_rub, got: provider.amount_rub } })]
      );
      await client.query('COMMIT');
      console.error('[billing] сумма не совпала', paymentId, 'ждали', p.amount_rub, 'пришло', provider.amount_rub);
      return { ok: false, reason: 'сумма не совпадает' };
    }

    const cab = (await client.query(
      `SELECT trial_ends_at, paid_until FROM auth.cabinets WHERE cabinet_id = $1 FOR UPDATE`,
      [p.cabinet_id]
    )).rows[0];
    const next = extendPaidUntil(cab, p.months);

    await client.query(`UPDATE auth.cabinets SET paid_until = $1 WHERE cabinet_id = $2`, [next, p.cabinet_id]);
    await client.query(
      `UPDATE billing.payments
          SET status = 'succeeded', paid_until_before = $2, paid_until_after = $3, updated_at = now()
        WHERE payment_id = $1`,
      [paymentId, cab.paid_until, next]
    );
    await client.query('COMMIT');
    return { ok: true, paid_until: next };
  } catch (e) {
    await client.query('ROLLBACK');
    console.error('[billing] зачисление не удалось', paymentId, e.message);
    throw e;
  } finally {
    client.release();
  }
}
```

```js
// POST /api/billing/webhook/<secret> — уведомление от ЮKassa.
// Уведомления не подписываются, поэтому телу не верим: секрет в URL отсекает
// случайных гостей, список сетей — посторонние адреса, а решает всё
// перепроверка платежа через API провайдера внутри creditPayment.
import { NextResponse } from 'next/server';
import { creditPayment } from '@/lib/billing-credit.js';
import { query } from '@/lib/db.js';

export const runtime = 'nodejs';
export const dynamic = 'force-dynamic';

// Сети ЮKassa (список из их документации, переопределяется через env).
const DEFAULT_NETS = ['185.71.76.', '185.71.77.', '77.75.153.', '77.75.156.', '77.75.154.', '77.75.155.', '2a02:5180:'];

function allowedIp(req) {
  const nets = (process.env.SAAS_YOOKASSA_IPS || DEFAULT_NETS.join(','))
    .split(',').map((s) => s.trim()).filter(Boolean);
  if (process.env.SAAS_YOOKASSA_MOCK === '1') return true; // мок ходит с localhost
  const ip = (req.headers.get('x-forwarded-for') || '').split(',')[0].trim();
  return nets.some((n) => ip.startsWith(n));
}

export async function POST(req, { params }) {
  const secret = process.env.SAAS_YOOKASSA_WEBHOOK_SECRET;
  // Неверный секрет — 404, а не 403: адрес вебхука не должен подтверждаться.
  if (!secret || params.secret !== secret) return NextResponse.json({ error: 'not found' }, { status: 404 });
  if (!allowedIp(req)) {
    console.warn('[billing webhook] чужой адрес', req.headers.get('x-forwarded-for'));
    return NextResponse.json({ error: 'not found' }, { status: 404 });
  }

  let body;
  try { body = await req.json(); } catch { return NextResponse.json({ error: 'Неверный JSON' }, { status: 400 }); }
  const paymentId = body?.object?.id;
  if (!paymentId) return NextResponse.json({ ok: true, ignored: 'нет id платежа' });

  // Тело сохраняем как есть — пригодится при разборе спорных случаев.
  await query(
    `UPDATE billing.payments SET raw = coalesce(raw,'{}'::jsonb) || $2::jsonb, updated_at = now()
      WHERE payment_id = $1`,
    [paymentId, JSON.stringify({ webhook: body })]
  ).catch((e) => console.error('[billing webhook] не удалось сохранить тело', e.message));

  if (body?.event !== 'payment.succeeded') return NextResponse.json({ ok: true, ignored: body?.event });

  try {
    const res = await creditPayment(paymentId);
    // Всегда 200: провайдер иначе будет слать повторы, а разбираться нам всё
    // равно по журналу и скрипту сверки.
    return NextResponse.json({ ok: true, credited: res.ok });
  } catch {
    return NextResponse.json({ ok: true, credited: false });
  }
}
```

```js
// scripts/billing-reconcile.mjs — страховка от потерянных уведомлений.
// Раз в час перезапрашивает у ЮKassa все платежи, висящие в pending, и
// дозачисляет оплаченные; висящие дольше суток помечает canceled.
// Клиент заплатил — доступ обязан открыться, даже если вебхук не дошёл.
import { readFileSync } from 'node:fs';

for (const line of readFileSync(new URL('../.env.local', import.meta.url), 'utf8').split('\n')) {
  const m = line.match(/^([A-Z_0-9]+)=(.*)$/);
  if (m && !process.env[m[1]]) process.env[m[1]] = m[2];
}

const { creditPayment } = await import('../lib/billing-credit.js');

const pending = await query(
  `SELECT payment_id, created_at FROM billing.payments
    WHERE status = 'pending' AND created_at > now() - interval '3 days'
    ORDER BY created_at`
);
let credited = 0, failed = 0;
for (const p of pending) {
  try {
    const res = await creditPayment(p.payment_id);
    if (res.ok && !res.already) { credited++; console.log('[reconcile] зачислен', p.payment_id); }
  } catch (e) {
    failed++;

  }
}
const stale = await query(
  `UPDATE billing.payments SET status = 'canceled', updated_at = now()
    WHERE status = 'pending' AND created_at < now() - interval '1 day'
```

```js
import { NextResponse } from 'next/server';
import { withCabinet } from '@/lib/withCabinet.js';
import { query } from '@/lib/db.js';
import { cabinetAccess, activePlans } from '@/lib/billing.js';

export const runtime = 'nodejs';
export const dynamic = 'force-dynamic';

export const GET = withCabinet(async (req, { cabinet }) => {
  const access = cabinetAccess(cabinet);
  const [plans, payments] = await Promise.all([
    activePlans(),
    query(
      `SELECT payment_id, plan_code, months, amount_rub, status, created_at, paid_until_after
         FROM billing.payments WHERE cabinet_id = $1
        ORDER BY created_at DESC LIMIT 20`,
      [cabinet.cabinet_id]
    ),
  ]);
  return NextResponse.json({

    until: access.until,
    days_left: access.daysLeft,
    grace_until: access.graceUntil,
    can_pay: cabinet.role === 'owner',
    plans,
    payments,
  });
```

```jsx
import { C } from "@/lib/palette.js";
// /cabinets/[id]/billing — единственная страница про деньги: состояние
// подписки, тарифы, история платежей.
import { useEffect, useState } from "react";

const FONT = "system-ui, -apple-system, Segoe UI, Roboto, sans-serif";
const fmtDate = (s) => (s ? new Date(s).toLocaleDateString("ru-RU") : "—");
const fmtMoney = (v) => `${Number(v).toLocaleString("ru-RU", { minimumFractionDigits: 0 })} ₽`;

const STATE_TEXT = {
  trial: (d) => `Пробный период до ${fmtDate(d.until)} — осталось ${d.days_left} дн.`,

  grace: (d) => `Срок закончился ${fmtDate(d.until)}. Доступ закроется ${fmtDate(d.grace_until)} — оплатите подписку.`,
  locked: () => `Доступ к проекту приостановлен. Оплатите подписку, чтобы продолжить.`,
};

export default function BillingPage({ cabinetId }) {
  const [data, setData] = useState(null);
  const [err, setErr] = useState("");
  const [busy, setBusy] = useState("");

  const load = () => {
    fetch(`/api/cabinets/${cabinetId}/billing`)
      .then((r) => (r.ok ? r.json() : Promise.reject(new Error("Не удалось загрузить состояние"))))
      .then(setData)
      .catch((e) => setErr(e.message));
  };

  // Вернулись из платёжной формы — ждём подтверждения от провайдера.
  const justPaid = typeof window !== "undefined" && new URLSearchParams(window.location.search).get("paid") === "1";
  useEffect(() => {
    if (!justPaid) return;
    const t = setInterval(load, 3000);
    const stop = setTimeout(() => clearInterval(t), 60000);
    return () => { clearInterval(t); clearTimeout(stop); };
  }, [justPaid, cabinetId]);

  async function pay(code) {
    setErr(""); setBusy(code);
    try {
      const r = await fetch(`/api/cabinets/${cabinetId}/billing/pay`, {
        method: "POST", headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ plan_code: code }),
      });
      const d = await r.json().catch(() => ({}));
      if (!r.ok || !d.confirmation_url) { setErr(d.error || "Не удалось создать платёж"); return; }
      window.location.href = d.confirmation_url;
    } catch { setErr("Сетевая ошибка"); }
    finally { setBusy(""); }
  }

  if (err && !data) return <div style={{ padding: 24, fontFamily: FONT, color: C.neg }}>{err}</div>;
  if (!data) return <div style={{ padding: 24, fontFamily: FONT, color: C.muted }}>Загрузка…</div>;

  const monthly = data.plans.find((p) => p.months === 1);
  const benefit = (p) => {
    if (!monthly || p.months === 1) return null;
    const full = Number(monthly.price_rub) * p.months;
    const save = Math.round((1 - Number(p.price_rub) / full) * 100);
    return save > 0 ? `выгода ${save}%` : null;
  };

  return (
    <div style={{ width: "100%", maxWidth: 760, padding: "24px 22px", fontFamily: FONT, color: C.ink }}>
      <h1 style={{ fontSize: 24, fontWeight: 800, margin: "0 0 20px" }}>💳 Подписка</h1>

      <div style={{
        background: data.state === "locked" || data.state === "grace" ? "rgba(255,107,107,.12)" : C.surface,
        border: `1px solid ${C.line}`, borderRadius: 12, padding: 20, marginBottom: 20, fontSize: 15,
      }}>
        {STATE_TEXT[data.state](data)}
      </div>

      {justPaid && data.state !== "active" && (
        <div style={{ background: "rgba(255,193,7,.12)", borderRadius: 12, padding: 16, marginBottom: 20, fontSize: 14 }}>
          Платёж обрабатывается — страница обновится сама, когда банк подтвердит оплату.
        </div>
      )}
      {err && <div style={{ background: "rgba(255,107,107,.12)", color: C.neg, padding: "10px 14px", borderRadius: 8, marginBottom: 16 }}>{err}</div>}

      {!data.plans.length ? (
        <div style={{ color: C.muted, fontSize: 14, marginBottom: 20 }}>Тарифы не настроены — напишите в поддержку.</div>
      ) : !data.can_pay ? (
        <div style={{ color: C.muted, fontSize: 14, marginBottom: 20 }}>Оплату производит владелец проекта.</div>
      ) : (
        <div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(200px, 1fr))", gap: 12, marginBottom: 24 }}>
          {data.plans.map((p) => (
            <div key={p.code} style={{ background: C.surface, border: `1px solid ${C.line}`, borderRadius: 12, padding: 20, textAlign: "center" }}>
              <div style={{ fontSize: 15, fontWeight: 700 }}>{p.title}</div>
              <div style={{ fontSize: 24, fontWeight: 800, margin: "8px 0" }}>{fmtMoney(p.price_rub)}</div>
              {benefit(p) && <div style={{ fontSize: 12, color: C.pos, marginBottom: 8 }}>{benefit(p)}</div>}
              <button onClick={() => pay(p.code)} disabled={!!busy} style={{
                width: "100%", padding: "10px", borderRadius: 8, background: C.accent, color: "#fff",
                border: "none", cursor: busy ? "default" : "pointer", fontWeight: 700, fontFamily: "inherit", fontSize: 14,
              }}>{busy === p.code ? "Создаём платёж…" : "Оплатить"}</button>
            </div>
          ))}
        </div>
      )}

      <h2 style={{ fontSize: 15, fontWeight: 700, margin: "0 0 12px" }}>История платежей</h2>
      {!data.payments.length ? (
        <div style={{ color: C.muted, fontSize: 14 }}>Платежей ещё не было.</div>
      ) : (
        <div style={{ background: C.surface, border: `1px solid ${C.line}`, borderRadius: 12, overflow: "hidden" }}>

            </div>
          ))}
        </div>
      )}
    </div>
  );
}
```

4. `npm run build && systemctl restart saas-web`, затем приёмка реальным платежом на минимальную сумму: проверить чек в почте, запись в кабинете ЮKassa, сдвиг `paid_until` и строку в `billing.payments`.
