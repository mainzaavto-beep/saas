# Рестайл панели, этап 1 «фундамент» — дизайн

Дата: 2026-08-22. Статус: направление одобрено владельцем (стиль «строгий
профи»; макет Сводки одобрен: «макет нравится, давай спеку этапа 1»).
Макет: артефакт c6b60865 (scratchpad `sysell-restyle-mockup.html`).

## Зачем

Владелец: панель выглядит «самодельно». Выбранный стиль — строгий
профессиональный (сдержанные цвета, один акцент, дисциплина типографики,
«дорогие» финансовые таблицы). Этап 1 меняет ТОЛЬКО внешний слой: значения
CSS-токенов, глобальную типографику и базовые стили общих контролов.
Ни одна формула, роут, запрос или композиция страниц не меняется.

## Как устроено сейчас (проверено)

- Все цвета страниц идут через `lib/palette.js` → `var(--токен)` →
  `app/globals.css`. Тёмная тема — дефолт `:root` (сине-навевые #0b1220/
  #131c2e), светлая — класс (`#f5f7fa/#ffffff`). Токены: `--bg --panel
  --panel2 --text --muted --accent --accent2 --danger --border --radius`
  + алиасы `--surface --surfaceAlt --ink --faint --line --pos --neg --warn
  --pink --blue`.
- Шрифт: системный стек, задан и в `globals.css:59`, и локальными
  константами `FONT` в страницах (одинаковая строка).
- Числа в таблицах — обычные (не табличные) цифры, выравнивание местами
  левое.

## Компоненты этапа 1

### 1. Новые значения токенов (обе темы)

`app/globals.css` — только ЗНАЧЕНИЯ, имена токенов не трогаем (иначе
задели бы 30 страниц). Палитра из одобренного макета:

Светлая: `--bg #FAFAF9` (тёплый камень вместо голубоватого), `--panel
#FFFFFF`, `--panel2 #F4F4F2`, `--text #1C1D21`, `--muted #6E7076`,
`--faint #9A9CA0`, `--border #E7E6E3`, `--accent #2E5CE6`, `--pos #177E4D`,
`--neg #C6373C`, `--warn #B7791F`, `--danger = --neg`.

Тёмная: `--bg #131417` (нейтральный графит вместо синего), `--panel
#1B1C20`, `--panel2 #222327`, `--text #ECECEA`, `--muted #9A9CA3`,
`--faint #6E7076`, `--border #2A2B30`, `--accent #6B8DF2`, `--pos #4CC38A`,
`--neg #E5636A`, `--warn #D9A44A`.

Вторичные акценты приглушаются, не удаляясь: `--accent2` → сдержанный
серо-бирюзовый (свет `#0F766E` / тьма `#3FA796`), `--pink` → приглушённый
терракот (свет `#B45341` / тьма `#D07B62`) — страницы, которые их
используют, перестают пестрить, но ничего не ломается. `--radius 12px` →
`10px`. Новый токен `--shadow` (две мягкие тени из макета, своя на тему) —
добавляется в globals.css; применение в страницах — этап 2 (этап 1 может
применить его только в общих классах globals/cabinet.css).

### 2. Типографика

- Глобально `body { font-variant-numeric: tabular-nums; }` — моноширинные
  цифры во всех таблицах/плитках сразу (главный признак финансового
  продукта; текстовым абзацам не вредит).
- Единый шрифтовой стек остаётся системным (внешние CDN запрещены
  протоколом; self-hosted шрифт — кандидат этапа 2, отдельным решением).
- В `globals.css` — базовые правила: ссылки цветом `--accent` без
  подчёркивания до ховера; заголовкам `letter-spacing: -0.01em`.

### 3. Базовые стили общих контролов

Только в `app/globals.css` / `app/cabinets/[id]/cabinet.css` (общие
классы, которые уже используются страницами, — инвентаризация классов
входит в план): кнопки/чипы/инпуты — рамка `--border`, фон `--panel`,
радиус `--radius`, ховер через `color-mix`; таблицы, где есть общий
класс, — тонкие разделители, `th` в верхнем регистре 11px с
letter-spacing. Инлайновые стили страниц НЕ трогаем (этап 2).

### 4. Показ владельцу

До деплоя: скриншоты «до/после» (светлая+тёмная) трёх страниц — Обзор,
Сводка, P&L — механизм: локальная сборка не нужна, правка токенов
безопасно деплоится на прод только ПОСЛЕ ок владельца по скриншотам из
dev-сборки? НЕТ: `next dev` в проде запрещён. Порядок: правки → `npm run
build && systemctl restart saas-web` → владелец смотрит живую панель →
если «не то», откат = git revert + build (правки чисто косметические,
откат безопасен и быстр). Владельца предупредить ДО деплоя.

## Что НЕ входит (этап 2 и далее)

Композиция страниц (иерархия плиток, спарклайны, «главная цифра крупно»),
инлайновые стили страниц, публичная часть (лендинг/логин), self-hosted
шрифт, тёмно/светлые скриншоты в маркетинге, изменение любых цифр,
формул, роутов, текстов данных.

## Ограничения (наследуются)

Панель деплоится только `npm run build && systemctl restart saas-web`;
сторожа после деплоя: `check-profit-canon.mjs` (1, 1008),
`profit-snapshot.mjs --verify` — ALL PASS (правки не касаются данных —
любое расхождение = баг); тексты по-русски. Приёмка: владелец смотрит
живую панель (обе темы) и говорит «ок»/«откати».
