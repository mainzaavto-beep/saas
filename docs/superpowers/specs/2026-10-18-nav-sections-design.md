# Навигация «разделы сверху, подразделы слева» (образец mptochka) — дизайн

Дата: 2026-10-18. Решение владельца: раскладка утверждена в чате 18.10 («подходит, делай»).
Образец — скрин «Платёжного календаря» mptochka (тот же, что для `/fin-calendar`).

## Цель

Сейчас меню кабинета — одна горизонтальная полоса: вперемешку одиночные ссылки и три выпадашки
(9/8/11 пунктов). Нужна трёхуровневая навигация как в образце:

1. **Сверху** — глобальные разделы (Аналитика · Товары · Закупки · Финансы).
2. **Слева** — панель подразделов выбранного раздела; подраздел с вкладками помечен «›».
3. **Над страницей** — вкладки внутри подраздела (если их больше одной).

## Раскладка

| Раздел | Слева | Вкладки |
|---|---|---|
| Аналитика | Главная · Дашборд показателей · РНП · Сводка по товарам · Заказы › · Поиск и запросы · ABC анализ · Отзывы | Заказы: Заказы · Матрица заказов · Заказы по времени · География |
| Товары | Склады и индексы · Остатки › · Процент выкупа · Себестоимость | Остатки: Остатки на МП · Остатки склад/ФФ · Отгрузки · Перемещение |
| Закупки | Закупки · Доставлено на склад · Потребность · План закупок | — |
| Финансы | Прибыль › · Деньги › · Расходы › · Баланс (owner) · Премия (owner, manager) | Прибыль: Сводка по прибыли · Юнит-экономика · План продаж; Деньги: ДДС · План поступлений · Платёжный календарь; Расходы: Сопутств. расходы · Самовыкупы |

Вне разделов: 🔔 Оповещения и ✨ Что нового — иконки справа в верхней полосе; Поддержка, Подписка,
Настройки, Выход — блок пользователя внизу левой панели. Переключатель проекта и темы — справа сверху.

Страницы без пункта меню подсвечивают «родителя» (алиасы): `/detail` → Сводка по товарам,
`/warehouses` → Склады и индексы, `/ff-stock` → Остатки, `/buyer-portrait` → Сводка по товарам,
`/briefing` → Главная. `/settings`, `/team`, `/content`, `/alerts`, `/whats-new`, `/support`,
`/billing` — вне разделов: в верхней полосе нет активного раздела, слева показываются подразделы
«Аналитики» без активного пункта (панель не исчезает и не прыгает по ширине).

## Устройство

- `lib/cabinetNav.js` — чистые данные и функции, без React и БД:
  `NAV` (дерево раздел → пункт → вкладки, поле `roles`), `ALIASES`, `navForRole(role)`,
  `resolveNav(path, nav)` → `{ sectionKey, itemKey, tabHref }`, `firstHref(node)`.
  Активность — по префиксу пути (`/detail?nm=…` и вложенные пути тоже).
- `app/cabinets/[id]/CabinetNav.jsx` — клиентский компонент (`usePathname`): верхние разделы,
  левая панель, вкладки. Активный пункт считается на клиенте — это заодно чинит старую проблему
  «подсветка активной вкладки не работает» (серверный layout в App Router не перерисовывается
  при переходах по `<Link>`, а подсветка бралась из заголовка `x-pathname`).
- `layout.js` — данные (сессия, роль, баннеры, проекты) остаются на сервере; фильтр по роли —
  `navForRole` на сервере, в клиент уходит уже отфильтрованное дерево.
- Клик по разделу → первый видимый пункт раздела; клик по пункту с вкладками → первая вкладка.
- Свернуть левую панель («) — только иконки; состояние в `localStorage` (try/catch).
- Узкий экран (< 900px): левая панель скрыта, открывается кнопкой ☰ поверх контента.
- Стили — `globals.css`, токены палитры, обе темы.

Не делаем (YAGNI): поиск Ctrl+K, бейджи-счётчики у разделов, перенос внутренних вкладок страниц
(у `/fin-dds` свои подвкладки Операции/Отчёт/… — остаются четвёртым уровнем внутри страницы).
